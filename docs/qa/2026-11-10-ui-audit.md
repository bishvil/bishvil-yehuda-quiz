# UI and usability audit — 2026-11-10

Scope: local updated app, synthetic data, desktop 1366×900 and mobile-emulated
390×844. Expert review, DOM/accessibility snapshots, measurements and keyboard
navigation; no user research or full WCAG certification.

The complete self-contained screenshot report is available in this execution
workspace at `/workspace/artifacts/quiz-ui-audit-2026-11-10/report.html`.
It contains 22 inspected current-run screenshots and 11 flow steps. Screenshots
are intentionally kept out of the source repository. No production data was used.

## Main findings

1. **Host untimed dead end — fixed in this change.** With 6/12 answers and no
   deadline, the host could neither reveal nor advance; its banner also displayed
   remaining seconds. The host can now explicitly close/reveal the current
   untimed station. The server verifies the question timing, rejects timed early
   reveal and paused sessions, closes atomically and rejects later submissions.
   Informational stations can also be closed without answers. Captured before,
   enabled after, and successful reveal after clicking the action.
2. **Mobile drawer keyboard focus — open.** Seven focus stops enter the closed
   drawer offscreen at x=407 on a 390px viewport. Use inert/hidden state, an
   expanded state and correct focus restoration for the drawer.
3. **Editor accessibility/touch — open.** Small delete buttons (28×21), back
   button (44×20), and ambiguous glyph-only correctness controls. Answer inputs
   need individually meaningful labels. Raw checkbox sizes alone are not treated
   as failures because their labels can enlarge the target.
4. **GPS authoring/player context — open.** Authoring uses lat/lng instead of a
   location picker/search/radius preview. The player GPS view loses quiz title,
   station number and progress. Permission recovery needs device-specific help
   and an operator contact path. Foreground location checks are explicit clicks,
   not continuous automatic unlock while walking.
5. **Open-answer learning feedback — open.** Wrong answer shows only status and
   points when no custom explanation exists. Reveal an accepted answer afterward.
   Untimed player questions also need an explicit no-limit badge.
6. **Admin result semantics — open.** Content and unanswered stations appear as
   0% accuracy. Distinguish not-applicable and not-yet-answered. Translate raw
   in_progress statuses. Mobile summary is unnecessarily tall.
7. **Brand labels and polish — open.** Quiz cards display raw brand UUIDs instead
   of resolved name/logo. New controls use native black borders/blue checkboxes
   alongside the established rounded green controls. Fold advanced branding,
   add participant preview, and keep host actions visible with long player lists.

Live map tiles/RTL, real phone GPS, Safari, screen readers, phone keyboards,
Google OAuth and camera scanning remain outside this verified scope. No loaded
map screenshot could be accepted in the restricted environment. Recommendations
other than the untimed-host blocker remain unapplied.
